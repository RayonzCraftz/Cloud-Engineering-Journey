Cloud computing adalah penggunaan resource komputasi jarak jauh tanpa harus memiliki dan mengelola hardware server secara fisik karena seorang cloud engineer menyewa server yang berada di data center suatu service (AWS, Azure, GCP, dan lain-lain) jadi kita hanya mengelolanya lewat laptop/PC saja. 
```
Model layanan Cloud:
1) IaaS - Infrastructure as a Service
disini kita menyewa resources server secara 
penuh untuk diset-up dan dikelola (seperti OS, 
data, konfigurasi, dan lain-lain. 

2) PaaS - Platform as a Service
platform ni memungkinkan kita untuk mendeploy 
dan menjalankan aplikasi/web secara langsung 
tanpa perlu mengelola resource secara 
menyeluruh (yang dikelola adalah aplikasi, 
code, dan beberapa konfigurasi). 

3) SaaS - Software as a Servuce
ini adalah software yang sudah tersedia dan 
siap digunakan (seperti instragam, google 
drive, dan lain-lain) sehingga tidak perlu mengelola apapun.
```
